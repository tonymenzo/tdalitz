# **tdalitz**

`tdalitz` generates flavour-tagged, time-dependent decays of a neutral meson ($D^0$, $B^0$, $B_s^0$) to three spin-0 particles.

Given an amplitude table *i.e.* the complex amplitude of each resonance component, evaluated by an amplitude-analysis package (e.g. Laura++) on a fixed set of Dalitz-plot points, `tdalitz` returns a set of events $(s_{12}, s_{13}, \tau, \text{tag})$, where $\tau$ is the decay time and the tag is the meson flavour at production.

## Quick start

```bash
python scripts/generate.py b0                                   # 10k events per tag -> events_b0.npz
python scripts/generate.py b0 --n-events 5000 --seed 7          # sample size (per tag) and seed
python scripts/generate.py bs --sigma-tau 0.03 --mistag 0.2     # time resolution (lifetimes), mistag rate
python scripts/generate.py d0 --out toys/d0_seed3.npz --seed 3  # output file
python scripts/generate.py --list                               # available channels
```

Channels are `d0`, `b0` and `bs` ($D^0$, $B^0$, $B_s^0 \to K_S^0\pi^+\pi^-$), and `b0_3pi` ($B^0 \to \pi^+\pi^-\pi^0$, generated as at a $B$ factory).

Python 3.9+ and NumPy are the only requirements (`pip install -r requirements.txt`); the tests, validation and figures need `requirements-dev.txt`.
Before generating events, download the reference tables into `tables/`:

```bash
gh release download --pattern '*.npz' --dir tables
```

or get `d0.npz`, `b0.npz`, `bs.npz` and `b0_3pi.npz` by hand from the [latest release](../../releases/latest).

Each run writes one `.npz` file holding both tags, with one entry per event in each of these arrays:

| array | contents |
| --- | --- |
| `s12`, `s13` | $m^2(h\pi^+)$, $m^2(h\pi^-)$ in GeV², with $h = K_S^0$ ($\pi^0$ for `b0_3pi`) |
| `tau` | decay time in lifetimes ($\Delta t$ for `b0_3pi`) |
| `tag` | flavour tag as measured: +1 for $P^0$, −1 for $\bar P^0$ |
| `true_tag` | production tag before mistag |
| `index` | row of the amplitude table each event came from |

The file also stores the settings used: seed, mixing parameters, detector options and table provenance.
The exact meaning of `tau` and `tag` in each mode is defined in [`docs/conventions.md`](docs/conventions.md).

## Model

```math
\frac{d\Gamma_+}{ds_{12}\, ds_{13}\, d\tau} \propto e^{-\tau} \Big|A g_+(\tau) + \frac{q}{p} \bar A g_-(\tau)\Big|^2
```
```math
A = \sum_r c_r F_r, \quad \bar A = \sum_r \bar c_r \bar F_r,
```
for a meson produced as $P^0$, with $c_r$ the complex coefficients and $g_\pm$ the mixing factors. For $\bar P^0$, swap $A \leftrightarrow \bar A$ and $q/p \to p/q$. Events are generated by exact accept/reject in $(s_{12}, s_{13}, \tau)$. All conventions (daughter order, CP conjugation, mixing parameters and their relation to PDG/HFLAV, the $B$-factory $\Delta t$ mode, tag definitions) are collected in [`docs/conventions.md`](docs/conventions.md).

## Amplitude tables

Tables contain $N$ points drawn uniformly over the Dalitz plot, with the complex amplitudes $F_r$ and $\bar F_r$ evaluated at each point for each of the $R$ resonance components (two arrays of shape $N \times R$).

The amplitude package provides:

* the component amplitudes $F_r(s_{12}, s_{13})$: lineshape, angular factor, barrier factors, normalization;
* the CP-conjugate amplitudes $\bar F_r(s_{12}, s_{13})$;
* the particle masses.

`tdalitz` defines the rest *i.e.* the coefficients, mixing, time evolution, tagging, event generation, detector effects and exact likelihoods.

### Reference tables

| table | decay | components | coefficients | time-dependent analyses |
| --- | --- | --- | --- | --- |
| `d0.npz` | $D^0 \to K_S^0\pi^+\pi^-$ | 6 | BaBar 2010, 6 of its components; the $\pi\pi$ S-wave (15%) is omitted | BaBar 2010 [[arXiv:1004.5053](https://arxiv.org/abs/1004.5053)], LHCb 2021 [[arXiv:2106.03744](https://arxiv.org/abs/2106.03744)] |
| `b0.npz` | $B^0 \to K_S^0\pi^+\pi^-$ | 9 | BaBar/Belle content; fit fractions approximate, strong phases assumed | BaBar 2009 [[arXiv:0905.3615](https://arxiv.org/abs/0905.3615)], Belle 2009 [[arXiv:0811.3665](https://arxiv.org/abs/0811.3665)] |
| `bs.npz` | $B_s^0 \to K_S^0\pi^+\pi^-$ | 6 | illustrative; no measured model exists | none; first observed by LHCb 2013 [[arXiv:1307.7648](https://arxiv.org/abs/1307.7648)] |
| `b0_3pi.npz` | $B^0 \to \pi^+\pi^-\pi^0$ | 3 | BaBar 2013 $\rho^\pm$, $\rho^0$ amplitudes, fitted to its published U and I coefficients; $\rho(1450)$ omitted | BaBar 2013 [[arXiv:1304.3503](https://arxiv.org/abs/1304.3503)], Belle 2007 [[arXiv:hep-ex/0701015](https://arxiv.org/abs/hep-ex/0701015)] |

The tables have 1M points each and are attached to the [releases](../../releases) (see [Quick start](#quick-start)). 

If needed, additional tables can be generated using `scripts/export_tables.py`, but require ROOT and Laura++. The models, coefficients and mixing parameters are defined in `src/tdalitz/channels.py`. In the $K_S^0\pi^+\pi^-$ channels, we have set each resonance contribution (its fit fraction) to match that of the published analysis listed in the table above. In `b0_3pi`, the amplitudes are fitted to the published BaBar results (see `scripts/fit_b0_3pi_amplitudes.py`).

### CP violation

The generator supports all three types of CP violation. The reference channels include:

| type | parameter | `d0` | `b0` | `bs` | `b0_3pi` |
| --- | --- | --- | --- | --- | --- |
| in decay (direct) | $\bar c_r \neq c_r$ beyond a strong phase | none | none | none | measured ($\lvert\bar c_r\rvert \neq \lvert c_r\rvert$) |
| in mixing | $\lvert q/p\rvert \neq 1$ | none | none | none | none |
| in interference between mixing and decay | $\arg(q/p\,\bar A/A) \neq 0$ | none | $\arg(q/p) = -2\beta = -0.79$ | $\arg(q/p) = -\phi_s = +0.037$ | measured, varies across the plot |

Note that `d0` is therefore CP-conserving. CP violation in decay is switched on with `Coefficient(..., weak=phi)` on any component, or `Coefficient.from_complex(c, c_bar)` for independent values, and CP violation in mixing with `MixingParameters(qp=...)` (see [Python usage](#python-usage)).
Mixing-induced effects in `d0` are practically unobservable at these sample sizes, since $x \approx 0.004$; CP violation in decay does not need mixing and can be studied in all three channels.

To make a new table with Laura++, see [`src/tdalitz/exporters/README.md`](src/tdalitz/exporters/README.md).

## Limitations

Events are drawn from the table's fixed set of Dalitz points, with replacement, so some events share a point: 6–13% of a 10k-event sample from a 1M-point table. Keep samples below about ~1% of the table size (10k events).

## Python usage

```python
import sys; sys.path.insert(0, "src")   # run from the repository root
import numpy as np
from tdalitz import AmplitudeTable, Coefficient, MixingParameters, generate_pair
from tdalitz.channels import CHANNELS

table = AmplitudeTable.load("tables/b0.npz")
ch = CHANNELS["b0"]
rng = np.random.default_rng(0)
b0, b0bar = generate_pair(table, ch.coefficients, ch.mixing, n_events=10_000, rng=rng)

# change the physics without touching the table
coeffs = dict(ch.coefficients)
coeffs["rho0(770)"] = Coefficient(magnitude=0.31, phase=2.0, weak=0.3)  # direct CPV on the rho
mixing = MixingParameters(x=0.77, y=0.0, qp=np.exp(-0.5j))
b0, b0bar = generate_pair(table, coeffs, mixing, n_events=10_000, rng=rng)
```

## Package layout

| module | contents |
| --- | --- |
| `kinematics` | Dalitz-plot boundaries, phase-space sampling, square-Dalitz coordinates (`FinalState`) |
| `amplitude` | table format, coefficients, fit fractions (`AmplitudeTable`, `Coefficient`) |
| `channels` | the reference channels: models, coefficients, mixing parameters (`CHANNELS`) |
| `mixing` | $g_\pm$ and tagged rates (`MixingParameters`, `tagged_rate`) |
| `generate` | event generation (`generate_tagged`, `generate_pair`) |
| `detector` | time resolution and mistag (`apply_time_resolution`, `apply_mistag`) |
| `likelihood` | exact densities, log-likelihood, KL divergence, Asimov significance |
| `validation` | exact expected histograms and $\chi^2$ tests |
| `exporters.laura` | Laura++ to table; needs ROOT |
